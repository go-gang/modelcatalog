# modelcatalog

Каталог моделей и Go-инструмент для сборки снимков из проверенных публичных
metadata. Приложение получает JSON и может встроить его в свой бинарь.
Генератор не нужен приложению во время работы.

В каталоге есть OpenAI API, ChatGPT/Codex, Anthropic и OpenRouter. Он содержит
точные ID моделей, возможности, лимиты, настройки протокола и известные цены.
API и подписочные каналы имеют отдельные записи.

Профиль `text-streaming-functions-v1` охватывает текстовый ввод, потоковый
текстовый ответ и вызов функций; изображения на входе поддерживаются опционально.
Это отобранная часть моделей провайдеров. Неизвестные значения остаются
неизвестными, возможности не выводятся из названия модели.

## Использование

Требуются Go 1.27 и mise. Из корня этого репозитория:

```sh
make generate
make check
```

Генерация создаёт `models.json` и `snapshot.json`. Manifest содержит ревизию,
дату снимка, профиль, источники и SHA256 точных байтов каталога. `make check`
запускает тесты, vet и проверяет, что оба файла соответствуют исходникам.

Подключение к другому Go-проекту:

```sh
mise exec -- go get -tool github.com/go-gang/modelcatalog/cmd/modelcatalog@<version>
mise exec -- go tool modelcatalog -output models.json -manifest snapshot.json
mise exec -- go tool modelcatalog -output models.json -manifest snapshot.json -check
```

Вместо `<version>` укажите выбранную версию. Для отдельного tools-модуля
можно добавить `-modfile=tools/go.mod` к `go get` и `go tool`.
Каталоги назначения должны существовать. `-check` проверяет оба файла
побайтно и возвращает ошибку, если файл отсутствует или устарел, без перезаписи.

Входные данные встроены в инструмент: он работает из любого каталога,
без checkout исходников, ключей и сети. Первая загрузка Go-модуля и его
зависимостей может потребовать сеть. Сохраняйте файлы модуля и оба JSON
в репозитории приложения, чтобы обновления были воспроизводимыми.

## Обновление данных

`source/reviewed.json` содержит проверенные записи нативных провайдеров
и явные переопределения OpenRouter. `source/openrouter.json` хранит
нормализованный снимок публичного API. Соседние provenance-файлы фиксируют
источники, hashes и основания решений. `source/snapshot.json` задаёт
ревизию, дату и профиль.

После изменения источников обновите provenance и ревизию, затем выполните
`make generate` и `make check`. Генератор проверяет hashes, согласованность
ревизий, профиля и происхождение каждой нативной записи. Сроки доступности
оцениваются на дату снимка, поэтому повторная сборка даёт те же байты.

Приложение само управляет авторизацией, адресами API, ограничениями своего
транспорта и локальными настройками. Каталог не подтверждает доступ аккаунта
к модели. Формат и ограничения описаны в [docs/format.md](docs/format.md).

Команды Go используют окружение mise. Настройки `GOCACHE`, `GOMODCACHE`,
`GOTMPDIR` и `TMPDIR` наследуются; CI хранит кэши и временные файлы в `.local/`.
